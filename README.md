# Library Master-Detail Layout

A Java-based **Master-Detail Layout for a library** developed as a project for the CSC360 course. The application displays a list of library books in a master view. When a book is selected, its complete information is displayed in the detail view.

## Project Overview

The project follows a **Master-Detail Layout**:

- **Master View:** Displays the list of available books.
- **Detail View:** Displays information about the selected book.


## Features

- View a list of library books
- Select a book from the master list
- Display detailed information about the selected book
- Search for books
- Display book availability
- Simple and user-friendly interface
- Java-based desktop application

## Book Information

The detail section can display:

- Book Title
- Author
- Description
- Category
- Publisher
- Price Starting With ($)
- Publish Date (Month)
- Publish Date (Year)
